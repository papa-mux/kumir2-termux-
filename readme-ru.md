## О проекте

Этот репозиторий содержит патчи и конфигурацию для сборки **КуМир2** — свободной среды программирования для обучения — под **Termux** на Android. КуМир2 изначально не рассчитан на сборку с современными версиями Python, поэтому здесь собраны необходимые фиксы.

Включённые исполнители: Робот, Черепашка, Рисователь, Художник, Водолей, Кузнечик, Изооробот, Комплексные числа, Клавиатура, Раскраска.

## Способ 1 — Быстрая установка (готовая сборка)

Самый простой способ — скачать и запустить `install.sh`, который сам скачает готовый архив `kumir2-android.7z` из ветки `install`, распакует его и установит все файлы в `$PREFIX`:

```sh
curl -O -L "https://raw.githubusercontent.com/papa-mux/kumir2-termux-/install/install.sh"
```

```sh
bash install.sh
```

Скрипт спросит язык (English / Русский), сам поставит недостающие зависимости (`curl`, `p7zip`) и разложит бинарники, библиотеки и ресурсы по нужным папкам Termux.

## Способ 2 — Сборка из исходников

### Зависимости для сборки

```sh
pkg install cmake make clang git python qt5-qtbase qt5-qtsvg qt5-qttools pkg-config
```

| Пакет           | Для чего нужен                          |
|-----------------|--------------------------------------------|
| `cmake`         | Система сборки                            |
| `make`          | Сборка через сгенерированные Makefile      |
| `clang`         | Компилятор C/C++                          |
| `git`           | Клонирование репозитория                  |
| `python`        | Скрипты сборки КуМира                     |
| `qt5-qtbase`    | Базовые модули Qt5 (GUI, ядро)             |
| `qt5-qtsvg`     | Поддержка SVG-иконок в интерфейсе          |
| `qt5-qttools`   | Инструменты Qt5 (linguist, uic и т.д.)     |
| `pkg-config`    | Поиск библиотек при сборке                 |

### Сборка

```sh
git clone https://github.com/papa-mux/kumir2-termux-
cd kumir2-termux-
```

```sh
mkdir build && cd build
cmake ..
```

```sh
make
```

Установка после сборки:

```sh
make install
```

Полный список целей сборки (отдельные исполнители, IDE и т.д.):

```sh
make help
```

## Известные проблемы и фиксы

- Сборка на новых версиях Python требует патчей — они уже применены в этом репозитории.
- Если сборка падает на каком-то модуле — попробуй собрать его отдельно через `make <ЦельСборки>` из списка `make help` и посмотреть подробный вывод ошибки.
